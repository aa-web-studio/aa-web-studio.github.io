## Чек-лист обновления сайта

1. Внести изменения в локальную копию репозитория.
2. Проверить страницы локально (открыть HTML в браузере).
3. `git add -A → git commit -m "..." → git push origin main`.
4. GitHub Pages задеплоится за 1–2 минуты.
5. Кэш браузера: 10 минут (`max-age=600`). Любые изменённые картинки и CSS кэшируем через `?v=N` (например, `img/logo.jpg?v=2`) и повышаем версию при апдейтах.
6. Проверить живой сайт по URL (не по кэшу).
