Гитарная педаль NUX Mod-Core-Deluxe-MkII

247 BYN
Nux Mod Core Deluxe MkII - это педаль с 8 различными типами модуляции: ST.CH (стереохорус), CE-1, SCF CHO, SCF FLG, SCF P.M., U-VIBE CHO, U-VIBE VIB и PH-100. Переключайте типы модуляции с помощью поворотного переключателя Type. Nux Mod Core Deluxe MkII обеспечивает расширенную маршрутизацию сигнала благодаря функциям Send и Return. Легко разделяйте моносигнал для создания настраиваемых циклов эффектов. Кроме того, вы можете параллельно использовать два сигнала и использовать ручку Tweak в режиме Alt для смешивания сигналов. Используйте 3-позиционный переключатель для выбора режима. ST.
